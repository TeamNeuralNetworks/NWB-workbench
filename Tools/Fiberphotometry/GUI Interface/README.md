# NWB Converter GUI Tool

## Download Executable

The executable version of the NWB Converter GUI tool is available for download from:
[Download Link](https://seafile.unistra.fr/d/fcb93c937e7b4ba58621/)

## Features

* Convert experimental data to NWB format
* User-friendly graphical interface
* Standalone executable, no Python installation required

## Usage

1. Download the `.exe` file from the link above
2. Double-click to run the application
3. Follow the GUI prompts to convert your data

## System Requirements

* Windows 10 or later
* At least 4GB RAM
* No additional software dependencies required
